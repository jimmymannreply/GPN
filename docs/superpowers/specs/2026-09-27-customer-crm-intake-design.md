# Customer flow: CRM → Intake → Scope → Plan — Design Spec

**Date:** 2026-09-27  
**Status:** Approved (conversation — approach 1 + build)  
**Scope:** GPN `/customer` flow only

## Flow

1. Build my business case → format dialog (draft | ledger)  
2. Dashboard → Continue session  
3. **CRM** — search lookup OR quick-pick one of three demo accounts (no Google/Partner switcher)  
4. **Intake** (new) — chatbot for pain / CXO outcome / constraints + LinkedIn attendees (company already known)  
5. **Scope** — editable form prefilled from chat and/or CRM seed  
6. **Plan** — attendees from CRM/intake + session agenda  
7. Run → Next steps (unchanged)

## Non-goals

- Changing partner `/hackathon*` CRM behavior  
- Removing partner-home Google/Partner CRM audience helpers (unused on customer path)
